NIELIT Document Resizer

An easy image editor for passport photos, signatures and thumb impressions.

Select a folder, edit each image, then download each JPG separately.

1. Select your folder

Select the folder containing your images

Supported image types: JPG, JPEG, PNG and WebP

0 images Output JPG 150 DPI default

Your images are processed in your browser. The originals are not changed.

2. Your images

Tap an image to edit it. Review the image type and filename before saving.

Select a folder to display your images here.

3. Edit selected image

Choose an image from the list to begin editing.

Drag the image to reposition the crop. Drag a corner handle to change the crop size. The crop is fitted to the selected format's aspect ratio.

The default name ends in _edit. You can change it before downloading.

Select a folder to start.

Important information

The preset dimensions and KB ranges are configurable defaults; check the current NIELIT application notice for your particular exam. JPEG quality is adjusted to try to meet the size limit. Very small size targets may require visible quality loss, and some images cannot satisfy every requirement at once. The tool does not silently replace original files.
