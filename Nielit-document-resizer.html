NIELIT Document Resizer

Automatically resize Photo, Signature and Left Thumb Impression.

Same-folder workflow

Select a folder, assign three images, then process them together. Edited JPG files are saved in the same folder with an _edit suffix when folder writing is supported. Original files are preserved.

Configured defaults: Photo 132 × 170 px (5–50 KB); Signature 170 × 132 px (5–20 KB); Left Thumb 170 × 132 px (5–20 KB); 150 DPI. Verify the current NIELIT notice for your application.

Important

The tool saves edited files with an _edit suffix and leaves original files unchanged. This avoids losing originals if a conversion fails. The app needs folder-write permission to save directly into the selected folder. Otherwise, each result downloads separately.
