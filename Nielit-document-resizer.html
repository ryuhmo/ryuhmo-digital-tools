How saving works

When folder writing is available, the tool writes the processed images into the selected folder. It creates or updates the requested output filenames. It does not delete the selected source files automatically. This avoids losing originals if a conversion fails.

If folder writing is unavailable, the tool will offer individual JPG downloads instead. It will not claim that files were saved to the folder when they were not.
